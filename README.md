# Learn Economics with Phoebe

Economics fundamentals for data and AI teams. Two tracks: a six-session **Foundations** track
with no code (prices as information, incentives and elasticity, marginal thinking, market
failure, money and interest, games and moats) and a ten-session **Data and AI deep-dive** in
Python (demand from real rows, why the naive elasticity lies, pricing, the economics of a
prediction, network effects and data moats, auctions, labour economics of AI, information
economics of models, build-buy-rent, and a bench).

The running data is the public Brazilian E-Commerce dataset by Olist (Kaggle, CC BY-NC-SA 4.0).
On 203 products that repriced often enough to be read, the same 2,216 rows give a price
elasticity of +0.008 across products, -0.108 pooled, and -1.788 when each product is compared
with itself. The bench recomputes every rung in the browser.

Live: https://phoebefu6.github.io/learn-economics-with-phoebe/

Static HTML, CSS and JS. No build step. `materials/build-olist-elasticity.py` rebuilds every
Olist number and the bench panel from the Kaggle CSVs.
